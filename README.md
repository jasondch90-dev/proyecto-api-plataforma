# Proyecto API Plataforma Online 🎬

API RESTful desarrollada con Node.js, Express y Firebase Firestore, que permite gestionar usuarios y contenidos para una plataforma de streaming. El proyecto incluye una interfaz web básica para interactuar con la API desde el navegador.

## Tecnologías utilizadas
- **Backend:** Node.js, Express
- **Base de datos:** Firebase Firestore (Admin SDK)
- **Validaciones:** express-validator
- **Frontend:** HTML, CSS puro, JavaScript (Fetch API)
- **Herramientas:** Visual Studio Code, Thunder Client

## Requisitos previos
- Node.js instalado (v18 o superior).
- Una cuenta de Firebase con un proyecto creado y Firestore Database habilitado.
- Archivo de credenciales de Firebase (`serviceAccountKey.json`).
